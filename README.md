# 一蓮建設株式会社 ランディングページ

GitHub Pages でそのまま公開できる静的サイトです（最新版）。

## 構成
- `index.html` … メインLP（トップページ／求人がメイン）
- `recruit.html` … 採用情報ページ
- `exterior.html` … エクステリア事業部ページ（事業紹介・施工事例・お客様の声・お問い合わせフォーム）
- `access.html` … 所在地・アクセス（地図）
- `privacy.html` … プライバシーポリシー
- `support.js` / `image-slot.js` … ページ描画に必要なランタイム（削除しないでください）
- `*.jpg` / `*.png` / `*.webp` … 写真・ロゴ・アイコン

## ページ間リンク
- トップの「求人情報を見る／採用エントリー」→ `recruit.html`
- 事業紹介「エクステリア事業部」カード → `exterior.html`
- 各ページのヘッダー「メインページに戻る」→ `index.html`
- ヘッダーの「所在地」→ `access.html`、「プライバシーポリシー」→ `privacy.html`

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作成（例: `ichiren-lp`）。
2. このフォルダ内のファイルを **すべて** リポジトリにアップロード（`index.html` がルート直下に来るように）。
3. リポジトリの **Settings → Pages** を開く。
4. Source を **Deploy from a branch**、Branch を `main` / フォルダ `/ (root)` に設定して Save。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## メモ
- 全ページ **レスポンシブ対応**（スマホ／タブレットで自動的にレイアウト調整）。
- 写真はすべて実ファイルとして埋め込み済み。差し替えは同名ファイルを置き換えてください。
- お問い合わせフォーム・採用の各種ボタンは、送信するとメールソフトが起動します（office.ichiren@gmail.com 宛）。サーバー送信フォームが必要な場合は Formspree 等の外部サービスに繋げます。
- フォント（日本語ゴシック・明朝・英字）は Google Fonts から読み込むため、公開後もインターネット接続があれば正しく表示されます。
